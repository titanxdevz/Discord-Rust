# Full Report Template (internal, for the developer only)

Use H2 for sections. Skip sections that do not apply to the project.

## 1. Overview
Project type, client location, objective, deliverables, scope summary.

## 2. Requirements
Confirmed / Implied / Optional / Unknown, as four short lists. Assumptions listed separately.

## 3. Technical approach
Recommended frontend, backend, database, APIs and infrastructure. Keep it as simple as the scope allows.

## 5. Timeline
Earliest / Recommended / Risk-adjusted windows, with the dependencies they rely on.

## 6. Market research
Comparable table (see market-research.md), median, IQR, evidence mix, limitations. Regional notes.

## 7. Cost breakdown
Billable hours, hourly cost, labour, direct expenses (one-time vs recurring listed separately), contingency, project cost, fee%, buffer%, price math.

## 10. Risks
Technical, commercial, scope. One line of mitigation each.

Advance and milestones, revisions, warranty, maintenance, exclusions, change-request rule.

## 12. Final recommendation
One fixed price, why it is justified, what must stay excluded.
